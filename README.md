# Arma Dental Clinic Website (PHP)

Multi-page, SEO-focused PHP website for **Arma Dental Clinic**.

## Run locally

```bash
php -S localhost:8000
```

Open `http://localhost:8000`.

## Pages

- `index.php` - Home
- `about.php` - About clinic
- `services.php` - Services
- `testimonials.php` - Patient reviews
- `contact.php` - Contact and appointment booking

## Shared layout

- `includes/config.php` - global clinic data and URL helpers
- `includes/header.php` - SEO meta tags, canonical, schema, navigation
- `includes/footer.php` - footer, floating WhatsApp CTA, JS include

## Assets

- `assets/css/styles.css` - responsive UI styling
- `assets/js/main.js` - mobile menu and WhatsApp form behavior

## SEO files

- `robots.txt`
- `sitemap.xml`
